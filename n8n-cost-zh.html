n8n 到底要花多少钱？（2026 版，附实测账本）

搜这个问题的人，八成看到的是同一张截图：官网定价页，几个欧元数字。

但那不是你想问的。你真正想知道的是：这东西跑起来以后，一个月从我卡上扣多少钱？

我自己自托管跑了一条生产工作流，下面是真实的账单。

先说结论：月执行量 3000 次以内、工作流不调大模型的话，自托管成本几乎是零（一台 60 块/月的云服务器，或者一台闲着的旧电脑）。真正贵的是你调试花掉的时间，不是授权费。

一、官方价格（2026 年 10 月）

套餐 价格 执行次数 适合谁
社区版（自托管） 免费 不限 会跑 Docker 就行
Cloud Starter €20/月（年付） 2,500 不想碰服务器
Cloud Pro €50/月（年付） 按需 个人开发者上生产
Cloud Business €667/月 40,000 百人以内公司，要 SSO
Enterprise 联系销售 按需 有合规要求

定价页上有两件事它没告诉你：

第一，社区版不限执行次数。 Cloud 按执行次数收费，自托管按服务器收费。一旦你的月执行量过了几千次，这个区别就是全部。

第二，“执行”指整条工作流跑一遍，不是单个节点。 n8n 不按节点收费。一个 30 个节点的工作流，算 1 次执行。

二、我实际花了多少

我跑的是一条线索分级流水线：webhook 收到线索 → 清洗 → 去重 → 打分 → 分配给销售 → 汇总进每日简报。

项目 我的实际成本
n8n 社区版授权 €0
云服务器（2 核 4G，国内轻量云） 约 60 元/月
Docker 0
数据库 SQLite（自带），0
大模型 API 调用 0 元
每条线索的处理成本 0 元

最后一行值得单独解释。

三、这块是别人不会写进比价表的

我那套流水线用的不是大模型，是确定性规则引擎。所以处理一条线索的边际成本是精确的零——不发 token、不按次计费、没有速率限制。

如果同样的活我用大模型做：

方案 处理 1000 条的成本 行为
规则引擎 0 元 同样输入永远同样输出
大模型（小模型，每条 1 次） 约 1.5–10 元 每次跑结果会有一点点不同
大模型（大模型，每条 1 次） 约 15–110 元 对乱写的文本更强，但仍然不确定

单条成本看着都不算什么。乘以量之后就不是了。而且当客户问 “为什么这条线索昨天 62 分、今天 58 分” 的时候，你答不上来。

我用的一条判断标准：

  • 任务需要对不规整的自然语言做判断 → 上大模型
  • 任务需要一致、可审计、可复现的决策 → 用规则。大模型只做前置分桶，桶里面还是规则说了算

我见过的大部分“AI 自动化”项目，本质是第二种，被包装成了第一种。

四、自托管 vs Cloud：盈亏平衡点到底在哪

Cloud Starter：€20/月 ÷ 2,500 次 = 每次执行 0.008 欧。

一台 60 元/月的服务器，只要你不跑重计算，扛的执行量远不止 2,500 次。所以：

你的月执行量 更划算的
500 次以内 Cloud Starter — 贵一点，但零运维
500 – 3,000 次 差不多打平。看重时间就 Cloud，不介意碰服务器就自托管
3,000 次以上 自托管，明显

但有一项隐形成本：运维。自托管意味着备份、升级、证书、以及“它挂了得有人发现”。如果你不想管这些，那 €20 是值的——我不会为了让自托管显得聪明就去否认这一点。

五、真正贵的不是授权费

我做完一条生产工作流的真实时间账：

环节 耗时
搭工作流本身 约 2 小时
调一个字段求值的 bug（返回值被当表达式重新求值） 约 3 小时
调 webhook 冲突（旧工作流没删，重复监听同一个路径） 约 2 小时
修一个把手机号当预算的金额解析器 约 1 小时
写回归测试 约 1 小时
合计 约 9 小时

按一小时 150 元算，1350 元的时间，去搭一条月成本 60 块的东西。

授权费从来不是问题，调试才是。

六、比订阅费更贵的三件事

1. 静默失败。 某个节点开始返回 null，不报错。三周后你发现 CRM 里全是空值。从第一天就配错误分支，推到一个你真的会看的群里。

2. 重复的工作流。 老版本 n8n 里导入工作流会生成新 ID，旧的那条还在跑。两条工作流监听同一个 webhook 路径，先注册的那条赢。你改的是工作流 #4，实际在处理流量的是 #1，你改什么都没用。这个坑吃了我两小时。

3. 没有测试。 手上没有一组固定的“输入 → 期望输出”，每次改动都是赌。我那套就是一个几十行的脚本：喂进去一条，比对输出。够了。

七、这几个问题我直接答

n8n 免费吗？ 社区版免费，执行次数不限。你付的是服务器钱。

比 Zapier 便宜吗？ 量大就便宜得多。Zapier 按 task 收费，n8n 自托管按服务器收费。月 1 万次以上差一个数量级。月 200 次的时候，Zapier 的省心可能真的值那个钱。

要信用卡才能开始吗？ 不用。docker run 就跑起来了。

最低配什么服务器？ 2 核 4G 对小负载很舒服，1G 能跑测试。

大模型的费用呢？ 只有你自己选择调它才有。平台本身不强制。
